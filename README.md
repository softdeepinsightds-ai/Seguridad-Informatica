# ListView e Intents en Android

Aplicación Android desarrollada con Java y XML. Presenta un catálogo en un
`ListView` y abre una pantalla de detalle al tocar un producto, enviando su
nombre mediante un Intent explícito y un extra.

## Abrir en Android Studio

1. Abre Android Studio y selecciona **Open**.
2. Selecciona la carpeta `Ejercicio 13` (la carpeta que contiene este archivo).
3. Espera a que termine **Gradle Sync**. Si Android Studio lo solicita, instala
   Android SDK Platform 35 y usa JDK 17 para Gradle.
4. Crea o inicia un emulador desde **Device Manager**, o conecta un dispositivo
   Android con la depuración USB activada.
5. Selecciona el dispositivo y pulsa **Run** (▶). La aplicación se inicia en el
   catálogo; toca un producto para abrir su detalle.

La primera sincronización necesita conexión a Internet para descargar Gradle,
el Android Gradle Plugin y las plataformas Android que no estén instaladas.
